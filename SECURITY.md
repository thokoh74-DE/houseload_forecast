# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | ✅        |
| < 2.0   | ❌        |

## Reporting / Melden

🇬🇧 Report vulnerabilities via [GitHub Security Advisories](https://github.com/thokoh74-DE/houseload_forecast/security/advisories/new). Do **not** open public issues.

🇩🇪 Schwachstellen bitte über [GitHub Security Advisories](https://github.com/thokoh74-DE/houseload_forecast/security/advisories/new) melden. **Kein** öffentliches Issue erstellen.
